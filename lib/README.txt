jsQR.js
  QRコードの読み取りライブラリ jsQR 1.4.0 (https://github.com/cozmo/jsQR)
  ライセンス: Apache License 2.0 (https://www.apache.org/licenses/LICENSE-2.0)
  取得元: https://cdn.jsdelivr.net/npm/jsqr@1.4.0/dist/jsQR.js (2026-09-30 取得・無改変)
  用途: iPhone(Safari)やパソコンなど、ブラウザにQR読み取り機能(BarcodeDetector)が無い端末で、
        「カメラで読み込む」を使えるようにするため。QRコードの読み込み欄が出たときだけ読み込まれる。
