# images/ フォルダについて

`index.html` の `CONFIG` から参照される、謎の画像を置く場所です。

## 現在の状態

`map.png`(地図)は本物の画像 **`map.webp`**(三重大学構内マップ・競技かるたサークル作成)に差し替え済みです。
それ以外のPNGは、まだ自動生成した「準備中」の仮画像です。本番投入前に、実際の謎画像に差し替えてください
(ファイル名は変えないこと。`CONFIG` の `image` パスと一致していないと表示されません)。

| ファイル名 | 使用する謎 | 内容(確定後に差し替え) |
|---|---|---|
| `map.webp` | 謎2〜5(マップ謎)、謎10(LION謎)、下部バーの「地図」ボタン | **差し替え済み。** 三重大学構内マップ(競技かるたサークル作成)。**4つのマップ謎・LION謎・「地図」ボタンで同じ1枚の画像を共有します。** グリッドの17番(人文学部)と、14番付近に描かれたライオンのアイコンが、LION謎の「ライオン」「NO17」の2択に対応していると読み取れます。謎1(パソコンのパスワード)を解くと、参加者はこの画像を「地図」ボタンからいつでも見返せるようになります |
| `puzzle6_poster.png` | 謎6: ポスターの謎 | かるたサークルのポスターの画像。制作者名「刈田」の記載を忘れないこと |
| `puzzle7_koban.png` | 謎7: 交番の場所 | 交番の場所を導く謎の画像、募集中 |
| `puzzle8_anagram.png` | 謎8: アナグラム | アナグラム謎の画像。**メイリオ表示であること自体がヒント**なので、画像内のフォントもそれに合わせると良い |
| `puzzle9_file.png` | 謎9: ファイルのパスワード | パスワード付きファイルとメモの画像、募集中 |

## 画像を差し替えるときの注意

- ファイル名・拡張子は上表のとおりに保つこと(変える場合は `index.html` の `CONFIG` 内の `image` の値も
  同時に書き換える)。
- 参加者は謎を解く間、何度も画像を見返します。特にマップ謎とLION謎は**拡大して細部を確認する**前提の
  作りになっているので、ある程度解像度のある画像を用意してください(目安: 長辺1000px前後以上)。
- 容量が大きすぎると学祭当日の学内Wi-Fiで表示が遅くなる可能性があるため、1枚あたり数百KB程度に
  収まるよう書き出し時に圧縮することを推奨します。
- 画像はタップすると全画面表示になり、ピンチ操作またはダブルタップで拡大縮小できます(`index.html` 側の
  機能なので、画像を差し替えるだけで自動的に対応します)。
- 謎1(パソコンのパスワード)だけは画像を使わず、CSSで作ったPCロック画面ふうの見た目になっています
  (`CONFIG` の `lockScreen: true`)。この謎用の画像ファイルは不要です。
